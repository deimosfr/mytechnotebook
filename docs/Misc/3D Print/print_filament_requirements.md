## Introduction

This page is dedicated to the print filament requirements.

I've been using my Prusa MK4, MK4S and now Core One for a while now, and I have learned a few things about filament requirements. I struggled a lot with the filament requirements, so here are my notes.

Note: I never use glue or anything else to stick the print to the bed, I only use the sheet.

## Filaments

* PLA:
    * Can break easily, it shouldn't be used to support structures
    * Small/thin prints: use Smooth PEI sheet, it will stick better to the bed, so you can print without support most of the time
    * Other prints: use Satin Powder-Coadted sheet, it will stick well to the bed and will be easier to remove
    * Clean the bed with isopropyl alcohol before printing to maximize adhesion (I clean it around once every 10 prints)

* PLA+:
    * Same as PLA, but ~10x stronger

* PETG:
    * Never use Smooth PEI sheet, it will damage your sheet
    * Use Satin Powder-Coadted sheet, it will stick well to the bed and will be easier to remove
    * You can try Textured Powder-Coadted sheet, it will stick well to the bed less cleanly
    * Wait for the sheet to be fully cooled down before removing the print
    * Print with enclosure to avoid warping
    * If the filament is not glassy on printing, try to dry it
    * Strong print quality
    * Clean the bed with isopropyl alcohol before printing to maximize adhesion and wait ~1h before printing to maximize adhesion
        ** Use soap if you don't want to wait

* TPU/FLEX:
    * Use Textured Powder-Coadted sheet, it will stick well to the bed and will be easier to remove
    * Print slowly
    * Don't use High Flow nozzle
    * On the Nextruder, loosen the idler
    * Keep the filament dry
